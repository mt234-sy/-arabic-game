# لعبة اسم حيوان نبات جماد بلاد

جاهزة للنشر على GitHub Pages.

## النشر
1. أنشئ مستودعًا جديدًا في GitHub.
2. ارفع `index.html` و `manifest.json` إلى المستودع.
3. افتح Settings > Pages.
4. تحت Build and deployment اختر Deploy from a branch.
5. اختر Branch: `main` و Folder: `/ (root)` ثم Save.
6. بعد النشر سيظهر رابط الموقع في صفحة Pages.

اللعبة تحتاج اتصال إنترنت على الجهازين، وتعتمد على PeerJS للاتصال بين اللاعبين.
